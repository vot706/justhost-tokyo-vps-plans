## 常见问题

**东京 VPS 需要备案吗？**
服务器在日本，不需要 ICP 备案。域名如果解析到中国大陆的 CDN 节点或服务器，才涉及备案。

**日本 IP 能解锁日本流媒体吗？**
不保证。JustHost 东京的第三方测试里，IPv4 归属显示为阿联酋，能解锁的是日本 ChatGPT、美国 Netflix 这类组合，不是纯日本区。真需要日本原生 IP，JUSTG 那类明确标注“原生日本 IPv4”的产品更对路，价格也贵得多。

**年付能退吗？**
官网价格页没有列出退款条款。下单前通过工单问清楚，或者先按月付一个月验证线路和 IP，确认没问题再补年付。

**东京和香港、新加坡怎么选？**
用户在日本、韩国选东京；用户在中国大陆华南、港台，香港的物理延迟更低；用户分散在东南亚，新加坡更居中。机房位置决定物理延迟下限，回程线路决定实际体验，两个都要看。
